# PPT Outline

## Overview

《AI 厨娘·智能烹饪助手 —— 项目答辩》是一份 **24 页**的汇报型演示文稿，面向答辩评审与项目验收方。
结构采用金字塔原理（结论先行）：先给项目全貌与架构骨架，再展开三个核心模块、**完整的 LangGraph 图结构与子图拆解**、两段关键代码与真实界面，
随后诚实复盘六类问题与四个典型案例，最后收敛到答辩人的能力收获。
其中「重点模块与精彩代码」「问题及解决方案」「项目完成后的收获」三章为答辩规定必备内容。

- PPT 类型：Report / Summary（结论先行）
- 页数：24 页（4 章 + 封面 / 目录 / 结束页）
- 风格：**Business / Light Tech（浅色为主）**，底色 `#F3F6FA`，主色深青 `#0E7490`，强调暖橙 `#EA580C`，辅色靛蓝 `#4F46E5`
- 答辩人：肖裔雄

## Design Style

- **风格**：Business / Light Tech（浅色商务科技风），脱离深色底，适合教室投影与打印
- **底色**：全局统一 `#F3F6FA`，页面配以极淡网格装饰；内容以白色卡片承载
- **主色**：深青 `#0E7490`；强调色：暖橙 `#EA580C`；辅色：靛蓝 `#4F46E5`；中性：`#475569`
- **语义色约定**：风控/阻断用 `rose`，安全/通过用 `emerald`，编排/结构用 `indigo`，提醒/待办用 `amber`
- **字体**：标题 Montserrat + Noto Sans SC；正文 Inter + Noto Sans SC；代码与数字使用等宽字体
- **字号**：页面主标题 34–38px、卡片标题 17–19px、正文 13–14px、注释 11–12px
- **设计原则**：一页一主题、标题即观点；每页含 100–200 字正文与 3–5 个具体数据点；仅第 18 页使用真实截图，其余为纯排版
