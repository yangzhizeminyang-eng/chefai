## 0. 文档说明

### 0.1 本清单的用途

| 项 | 说明 |
| --- | --- |
| **是什么** | UI 原型（Figma / MasterGo）的**逐界面文字规格**，是设计稿与开发实现的共同基准 |
| **不是什么** | ❌ 不是视觉稿本身；❌ 不定义色值与像素级视觉（色值见 UI 设计稿 B-D2-2） |
| **读者** | UI 设计师（出稿依据）、前端（实现依据）、测试（用例依据）、甲方（评审依据） |

### 0.2 编号规则

| 前缀 | 含义 |
| --- | --- |
| `W-xx` | 阶段一 Web 演示端页面 |
| `P-xx` | 阶段二小程序页面 / 弹层 |
| `K-xx` | 管理后台页面 |
| `G-xx` | 全局组件（跨页面复用） |

### 0.3 状态提示的填写口径

> 🔴 需求文档 NFR-3.7 要求**所有列表/数据页必须处理「空 / 加载 / 错误 / 无权限 / 离线」五态**。本清单每行均填写状态提示，**空白即为漏项**。

| 状态 | 定义 |
| --- | --- |
| **加载** | 骨架屏 / 局部 loading / 进度态 |
| **空** | 无数据时的图标 + 文案 + **下一步行动按钮**（不得只留空白页） |
| **异常** | 网络错误 / 服务错误 / 超时，含「重试」 |
| **其他** | 无权限 / 离线 / 低置信降级 / 保守模式等特殊态 |

### 0.4 通用设计规范（PRD §5.5 / §5.6 已定义，本清单不重复色值）

| 项 | 规格 |
| --- | --- |
| 字号阶 | 小 14px / 标准 16px / 大 18px；**烹饪模式专档 ≥ 32px**（50cm 可读） |
| 点击区域 | 关键操作 **≥ 44×44pt** |
| 深色模式 | 全页面可用；对比度满足 WCAG AA |
| **不依赖颜色** | 安全提示必须**图标 + 文字**，需提供**灰度稿** |
| 安全色语义 | 危险（红 + ⛔）/ 警示（橙黄 + ⚠️）/ 信息（蓝灰 + ℹ️） |
| 免责声明 | 首页底部、菜谱详情、营养页、风控页**固定附着**（PRD §5.6） |
| **前端技术基座** | **阶段一 Web 演示端 + 管理后台 = Vue 3 + Vite + Element Plus**；**阶段二小程序 = uni-app**（⚠️ **Element Plus 是 Web 组件库，小程序不可用**） |
| **组件选用** | Web 端优先复用 Element Plus 既有组件：`el-table` / `el-card` / `el-steps` / `el-drawer` / `el-dialog` / `el-message` / `el-tag` / `el-form` / `el-progress`；**三类安全组件（G-01~G-03）必须在 Element Plus 之上二次封装**，不得直接沿用默认样式 |
| **AI 创新菜标识** 🆕 | 🔴 必须**图标 + 文字**双通道（**不得仅靠颜色**）；与常规菜谱在视觉上可区分；「未经人工审核」声明常驻，**不可关闭** |
| 阶段一 | 无导航框架，单页切换；无登录 |

## 1. 阶段一 Web 演示端（W-01 ~ W-06）

> **技术基座**：**Vue 3 + Vite + Element Plus**，构建为静态资源由 Nginx / FastAPI 托管。
> 页面内交互优先复用 Element Plus 组件（推荐列表用 `el-card` + `el-tag`；分步引导用 `el-steps` / `el-progress`；调度面板用 `el-table` + `el-drawer`；提示用 `el-message` / `el-alert`）。
> ⚠️ 阶段一**无登录、无导航框架**，单页切换；深色模式与大字模式按 §0.4 执行。
