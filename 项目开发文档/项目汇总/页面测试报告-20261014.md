## 3. 核心链路交互测试

### 3.1 推荐主链路（选食材 → 推荐 → 详情 → 烹饪）✅

```
/select 勾选「番茄、土豆、猪里脊」
  → 底部「已选 3 样」→ 点击「去推荐」
  → /recommend 正常返回（后端推荐服务连通）
  → 返回 2 道菜谱，附「现有食材组合有限，宁缺毋滥」如实说明
  → 点击「西红柿土豆炖牛肉」卡片
  → /recipe/1978 详情完整（含致敏原警示条：大豆）
  → 点击「开始做菜」
  → /cook/1469 分步引导，第 1 步「上一步」按钮正确置灰
```

### 3.2 烹饪模式交互 ✅

| 交互 | 结果 |
| --- | --- |
| 下一步（第 1 → 第 2 步） | ✅ 本地即时切换，进度条 5% → 10%，无需网络 |
| 计时器浮层 | ✅ 5 个预设计时 + 自定义计时可用 |
| 退出 | ✅ 二次确认弹窗，确认后正确回退至 /select |

### 3.3 风控一票否决链路 ✅（阶段一核心证据）

```
首页输入「发芽土豆能吃吗」→ 点击「问厨娘」
  → 后端风控闸门命中规则 FS-003（发芽/变青土豆 · 龙葵素）
  → 短路返回，前端跳转 /blocked
  → 页面完整呈现：风险说明 / 正确做法 / 就医引导 / request_id / 规则依据（FS-003@rules-v1.0）
  → 明确标注「本次请求未生成任何内容」
```
